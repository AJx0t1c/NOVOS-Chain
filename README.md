# NOVOS Chain 🚀

A simple Bitcoin-inspired blockchain built in **Python**.

## Features

* 🔗 Linked blockchain structure
* ⛏️ Proof-of-Work mining
* 🧾 Transaction ledger
* 💰 Automatic wallet balances
* 🚫 Overspending protection
* 🕒 Human-readable timestamps

## Run

```bash
python blockchain.py
```

## Example Output

```
⛏️ Block 0 mined!
⛏️ Block 1 mined!
⛏️ Block 2 mined!
⛏️ Block 3 mined!
❌ Transaction rejected: JARVIS only has 7 NOV
```

This project is part of the **NOVOS ecosystem** and is being developed as a learning project for blockchain, cryptography, and distributed systems.
